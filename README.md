## 🇪🇸 Español

Prototipo de aplicación web desarrollado para la gestión, ejecución y evaluación de procedimientos operativos.

### 🚀 Tecnologías Utilizadas
- **Frontend:** React.js (Vite), TailwindCSS
- **Backend:** Node.js, Express.js, SQLite
- **Infraestructura:** Docker, Cmder, Git

### 🛠️ Instalación Rápida
```bash
# Clonar repositorio
git clone [https://github.com/TU_USUARIO/sistema-gestion-procedimientos.git](https://github.com/TU_USUARIO/sistema-gestion-procedimientos.git)

# Backend
cd server && npm install && npm run dev

# Frontend
cd client && npm install && npm run dev
```
